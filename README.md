Schede delle demo dell'assistente AI di Stefano Pontalti (siti e assistenti AI, Trentino).
Ogni file `<slug>.json` è una demo: il Worker `chatbot-demo` la legge da qui quando non è già
pubblicata dentro il Worker, all'indirizzo https://chatbot-demo.stefanopontalti07.workers.dev/<slug>

Contengono solo fatti pubblici presi dai siti delle aziende. Nessun dato di clienti o lead.
Fonte: `automazioni/prodotti/chatbot-sito/demo/schede/` nel repo privato di lavoro.
